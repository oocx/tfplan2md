Firewall Rule Inline Diffing

See exactly which rules were added, modified, or removed—not confusing index-based array diffs.

azurerm

When firewall rule collections change, Terraform often shows confusing index-based diffs. tfplan2md understands the semantics of both network rules (IP/port-based) and application rules (FQDN-based) and presents a clear table showing exactly what changed.

Key Features

  • Displays all rule properties in a scannable table
  • Works for all azurerm_firewall_network_rule_collection and azurerm_firewall_application_rule_collection resources
  • Automatically applied—no configuration needed
