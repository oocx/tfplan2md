## Issue Breakdown

### 1. Missing Space Before Wrench Icon ⏳ **KNOWN ISSUE**

**Impact:** 19 files (41% of checked files)  
**Severity:** Medium  
**Status:** Previously identified as issue 3.2

**Problem:**
The wrench icon used to indicate changed attributes lacks a space between the count and the icon.

**Current Implementation:**
```html
| 2🔧 account_replication_type, tags.cost_center
```

**Style Guide Requirement (line 59):**
```html
| 2 🔧 account_replication_type, tags.cost_center
```
> Changed attribute summary for updates: `<count> 🔧 <attributes>` (non-breaking space between wrench icon and attributes)

**Examples:**
- artifacts/comprehensive-demo.md:74
- artifacts/comprehensive-demo-simple-diff.md:74
- artifacts/plan.md:34
- artifacts/azure-rm-batch-2-feature-test.md (3 occurrences)

**Fix Required:** Add non-breaking space between count and wrench icon in summary generation code.

---

### 2. Empty Resource Names in Summaries ⏳ **KNOWN ISSUE**

**Impact:** 6 files (13% of checked files)  
**Severity:** High  
**Status:** Previously identified as issue 2.2

**Problem:**
AzAPI resources without mapped friendly names display empty `<b></b>` tags instead of falling back to the Terraform resource name.

**Current Implementation:**
```html
<summary>➕ azapi_resource <b></b> — <code>🆔 myAccount</code> <code>🌍 westeurope</code></summary>
```

**Style Guide Requirement (line 54):**
> **Resource Name**: Bold + code-formatted (e.g., `<b><code>hub</code></b>`)

**Expected Implementation:**
```html
<summary>➕ azapi_resource <b><code>myAccount</code></b> — <code>🆔 myAccount</code> <code>🌍 westeurope</code></summary>
```
Or use Terraform resource name as fallback.

**Affected Files:**
- artifacts/azapi-mapped-resources-demo.md (3 occurrences)
- artifacts/azapi-mixed-mappings-demo.md (4 occurrences)
- artifacts/azapi-create-demo.md
- artifacts/azapi-update-demo.md
- artifacts/azapi-unmapped-resources-demo.md (2 occurrences)
- artifacts/azapi-complex-demo.md

**Fix Required:** Update AzAPI resource summary generation to use Terraform resource name when friendly name is unavailable.

### 4. H3 Headings Inside Details Blocks ⚠️ **NEW FINDING**

**Impact:** 4 files (9% of checked files)  
**Severity:** Medium  
**Status:** New compliance violation (different from fixed issue 2.1)

**Problem:**
Some older artifact files contain H3 headings inside `<details>` blocks, violating the heading hierarchy rules.

**Current Implementation:**
```html
<details>
<summary>...</summary>
<br>

### ➕ azapi_resource.complex_app
```

**Style Guide Requirement (line 160):**
> Maintains proper heading hierarchy (H3 for modules, no H4 for resources)

**Affected Files:**
- artifacts/azapi-uat-combined.md:23
- artifacts/azapi-nested-grouping-demo.md:23
- artifacts/static-analysis-comprehensive-demo.md:235
- artifacts/comprehensive-demo-nested.md:125

**Analysis:**
These files were NOT regenerated by `generate-demo-artifacts.sh`. They appear to be from older versions or specific test scenarios. This is distinct from issue 2.1 which was about the azapi template itself.

**Recommendations:**
1. Identify why these files weren't regenerated
2. Either add them to `generate-demo-artifacts.sh` or remove them if obsolete
3. Regenerate with latest version

### 5. Module Headers Without 📦 Icon ⚠️ **NEW FINDING**

**Impact:** 8 files (17% of checked files)  
**Severity:** Low  
**Status:** New compliance violation

**Problem:**
Module headers lack the 📦 icon specified in the style guide.

**Current Implementation:**
```markdown
### Module: `module.network`
```

**Style Guide Requirement (lines 168, 180):**
```markdown
### 📦 Module: `module.network`
```
> Modules are separated by horizontal rules (`---`) for clear visual breaks.  
> Module headers use the 📦 icon before the label with a non-breaking space.

**Affected Files:**
- artifacts/comprehensive-demo.md:665
- artifacts/comprehensive-demo-simple-diff.md:668
- examples/comprehensive-demo/report-with-sensitive.md:665
- artifacts/tool-column-uat.md:473
- artifacts/static-analysis-comprehensive-demo.md:481
- Plus 3 more files

**Fix Required:** Update module header generation to include 📦 icon.

### 6. Attribute Names in Backticks ⚠️ **NEW FINDING**

**Impact:** 1 file  
**Severity:** Low  
**Status:** Minor compliance violation

**Problem:**
One file has attribute names wrapped in backticks in tables, which violates the "Labels are Text" principle.

**Style Guide Requirement (line 18):**
> - **Attribute Names (Keys)**: Plain text.

**Incorrect:**
```markdown
| `location` | `eastus` |
```

**Correct:**
```markdown
| location | `eastus` |
```

**Affected Files:**
- 1 file detected (minor issue)

**Fix Required:** Ensure attribute names in tables are plain text, not code-formatted.
