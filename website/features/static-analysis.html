Static Code Analysis Integration

Combine Terraform plan changes with security findings from Checkov, TfLint, and Trivy in one unified report.

SARIF 2.1.0 Checkov TfLint Trivy

tfplan2md natively supports SARIF 2.1.0 format, allowing you to integrate security findings from multiple tools directly into your infrastructure change reports. Findings are automatically mapped to specific resources and attributes, creating a unified view of both changes and security issues.

How It Works

  1. Run your security tools — Generate SARIF output from Checkov, TfLint, Trivy, or any SARIF-compatible tool
  2. Pass SARIF files to tfplan2md — Use --code-analysis-results with file paths or wildcards
  3. Get a unified report — Findings are mapped to resources and displayed alongside plan changes

CLI Usage

Basic Usage 
# Generate Terraform plan
terraform show -json plan.tfplan > plan.json

# Run security tools
checkov -d terraform --framework terraform --output sarif -o checkov.sarif
tflint --format sarif > tflint.sarif
trivy config terraform --format sarif --output trivy.sarif

# Generate unified report
docker run -v $(pwd):/data -i oocx/tfplan2md \
  /data/plan.json \
  --code-analysis-results "/data/*.sarif" \
  --output /data/report.md

CLI Options

Option Description
--code-analysis-results <pattern> File path or wildcard pattern for SARIF files (e.g., *.sarif or **/*.sarif)
--code-analysis-minimum-level <level> Minimum severity to include (none, note, warning, error). Default: note
--fail-on-static-code-analysis-errors Exit with non-zero status if high or critical findings are present

Benefits

  • Unified View — See infrastructure changes and security findings in one report
  • Resource Mapping — Findings are automatically mapped to specific resources and attributes
  • Multi-Tool Support — Combine results from multiple security tools
  • PR Integration — Perfect for posting as PR comments alongside plan changes
  • Fail-Fast Option — Use --fail-on-static-code-analysis-errors to block PRs with critical issues

💡 Tip: Use wildcard patterns like **/*.sarif to automatically include SARIF files from subdirectories.
