## Retrospective timing and workflow maintenance

Feature and bug workflows now run Retrospective after Release Manager completes the release. Workflow Engineer is documented and shown as a separate Maintainer-triggered process, and post-release work can resume from its retained work-item directory after the source branch is deleted.

The workflow diagram now shows four numbered workflows in reading order with plain labels. Its website renderer preserves workflow headings and arrow geometry, and the website allows horizontal scrolling to keep the diagram readable on narrower screens.
