# UAT: `--details` Display Mode Feature

This artifact validates that the `--details` CLI argument correctly controls whether resource `<details>` blocks are expanded or collapsed.

## Feature Overview

Three modes:
- `--details closed` — all resource blocks **always collapsed**
- `--details open` — all resource blocks **always expanded**
- `--details auto` — (default) expands blocks **only for resources with code analysis findings**

---

## Mode 1: `--details closed` (All Collapsed)

Expected: All `<details>` blocks have **no** `open` attribute — they render collapsed.
