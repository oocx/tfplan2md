Azure DevOps Provider

Specialized support for Azure DevOps variable groups with semantic diffing and secret protection.

Partial Support

Support for Azure DevOps provider includes specialized rendering for variable groups, with additional resources planned.

Implemented Resources

  • Variable Groups (azuredevops_variable_group): Variable-level semantic diffing with secret value protection, Key Vault integration display, and unified regular/secret variable tables. See the Variable Groups feature page for details.

Planned Resources

  • Projects: Clear display of project settings and visibility
  • Pipelines: Build and release pipeline configuration diffs
  • Service Connections: Simplified view of connection details

Roadmap

We are actively looking for community feedback on which Azure DevOps resources are most critical for your workflows. Please check our GitHub issues to vote or contribute.
